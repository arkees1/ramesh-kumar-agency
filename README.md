## 🚀 Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this ZIP.
3. Go to **Settings → Pages**.
4. Under "Source", choose **main branch / root folder**.
5. Save — your website goes live in seconds.
